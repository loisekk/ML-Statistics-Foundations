## 📊 ML-Statistics-Foundations

A structured collection of core statistical concepts essential for Machine Learning, Deep Learning, and AI systems.

🚀 Overview

This repository is a curated compilation of my learning journey in Statistics for Machine Learning.
It covers fundamental to intermediate-level statistical concepts required to understand, build, and interpret modern AI models.

The goal of this repository is to:

Build a strong statistical foundation
Bridge the gap between theory and ML applications
Provide clear, structured notes for revision and reference
